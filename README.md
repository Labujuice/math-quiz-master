# Math Quiz Master (小朋友趣味數學挑戰網頁)

🔗 **[線上體驗 (Live Demo) 點此前往](https://labujuice.github.io/math-quiz-master/)**

這是一個專為兒童設計的隨機數學挑戰練習網頁，旨在透過趣味的扁平化介面、精美的視覺回饋與豐富的遊戲化機制（生命值、動態積分排行），提升小朋友學習數學的興趣。本系統為 100% 純前端靜態網頁，無須任何後端伺服器或資料庫，可直接以瀏覽器本地開啟或部署於 GitHub Pages 平台。

## ✨ 特色功能

- **🎨 兒童友善介面 (UI/UX)**
  - 延續簡潔扁平化設計（Minimalist Flat Design），配以明亮柔和的兒童友善配色。
  - 設計超大觸控按鈕與字體，針對平板、手機與桌機進行響應式版面最佳化。
  
- **🎵 獨立音樂與音效控制**
  - **背景音樂**：內建循環輕快背景音樂，並提供獨立開關。
  - **答題音效**：答對時發出清脆的 `丁咚 (Ding Dong)` 聲，答錯時發出警示的 `逼逼 (Buzzer)` 聲。
  - **設定選單**：首頁設有「⚙️ 設定」入口，支援拖曳拉桿即時微調音樂音量大小。

- **⚙️ 靈活客製化的出題規則**
  - **題型勾選**：支援加法 (`+`)、減法 (`-`)、乘法 (`×`)、除法 (`÷`) 多選出題。
  - **難易度選擇**：可設定一位數（0-9）、兩位數（10-99）、三位數（100-999）。
  - **防呆與進階設定**：
    - 可自由決定題目或答案是否可產生負數（若關閉，減法題目會防呆以確保被減數大於減數）。
    - 除法小數點支援：關閉時除法會自動調整為可整除題目；開啟時除數與被除數保持整數，但答案最多只會除到小數點後第一位，並防呆過濾無限循環小數。

- **✍️ 雙軌答題模式**
  - **選擇題**：自動生成 1 個正解與 3 個具迷惑性的鄰近干擾選項（支援小數與負數選項）。
  - **填充題**：網頁專屬的**兒童虛擬小鍵盤**（含數字、小數點、負號、倒退鍵、送出鍵），並阻斷平板或手機系統原生鍵盤彈出，避免遮擋畫面。
  - **防連點鎖定**：答題後系統自動鎖定操作 1 秒（顯示圈叉視覺反饋），防止連擊造成重覆扣生命值或重覆算分。

- **🏆 排行榜與加權積分系統**
  - **英雄榜 (Leaderboard)**：支援單機排行榜，透過 `LocalStorage` 紀錄最高積分的前 10 名成績，並同時顯示玩家「分數」與「積分」供參考。
  - **設定清除**：於設定選單內提供「清除英雄榜」按鈕，方便隨時清空本機紀錄。
  - **動態積分加權**（答對才可累積，用於英雄榜）：
    - **基礎分數**：每題答對基本分為 1 分。
    - **題型加權**：加法與減法為 `1.0 倍`，乘法與除法提高為 `1.5 倍`。
    - **位數加權**：一位數為 `1.0 倍`，二位數為 `1.5 倍`，三位數為 `2.0 倍`。
    - *計算公式：`得積分 = 1 × 題型倍率 × 位數倍率`*

- **🖨️ 改考卷與 A4 列印輸出**
  - 提供 10 題、20 題、30 題或「無限挑戰」模式。任何模式皆支援隨時點擊「結束測驗」提早交卷。
  - 結束後自動跳轉至一頁式考卷，詳細呈現姓名、時間、百分制分數及作答履歷。
  - 答錯題目下方會以鮮紅色自動標記「更正答案 / 正確答案」。
  - 支援瀏覽器原生列印 (`window.print`)，透過 `@media print` 專屬樣式，列印時將自動隱藏背景色、按鈕、音樂控制器與排行榜，以乾淨美觀的 A4 PDF 考卷呈現。

## 🛠️ 技術棧

- **HTML5**: 語意化結構。
- **CSS3 (Vanilla)**: 響應式佈局 (Flexbox/Grid)、自定義變數、按鈕動態點擊反饋及 `@media print` 列印樣式。
- **JavaScript (ES6)**: 數學出題防呆演算法、虛擬鍵盤阻斷實作、BGM/SFX 音訊控制與 `LocalStorage` 本機排行紀錄。

## 🚀 運行與部署

### 本地運行
本專案不需使用任何 Node.js 等編譯伺服器，直接在您的電腦上下載本專案：
1. 點擊 `index.html` 即可直接在瀏覽器中開始遊玩。

### GitHub Pages 靜態部署
1. 將此專案推送（Push）至您的 GitHub 儲存庫。
2. 前往該儲存庫的 **Settings** > **Pages**。
3. 將 **Source** 改為 `Deploy from a branch`。
4. 選擇您的主分支（例如 `main` 或 `master`）並點擊 **Save**。
5. 數分鐘後即可透過專屬網址點入訪問（例如：[https://labujuice.github.io/math-quiz-master/](https://labujuice.github.io/math-quiz-master/)）。
