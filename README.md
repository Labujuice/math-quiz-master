# Math Quiz Master (小朋友趣味數學挑戰網頁)

這是一個專為兒童設計的數學隨機練習網頁，旨在透過趣味的介面與簡單的遊戲機制（生命值、積分排行），提升小朋友學習數學的興趣。本系統為純靜態網頁，無需後端與資料庫，可直接部署於 GitHub Pages 或任何靜態網頁伺服器。

## ✨ 特色功能

- **🎨 兒童友善介面 (UI/UX)**：明亮配色、大字體、大按鈕，完美適應桌機與平板觸控。
- **🎵 背景音樂與音效**：內建循環輕快音樂（附開關），並在答題時提供明顯的視覺回饋。
- **⚙️ 高度客製化出題**：
  - 支援加、減、乘、除（可多選）。
  - 可選擇題目難度（1至3位數）。
  - 進階設定：允許題目或答案為負數、除法支援小數點（至第一位）。
- **🎮 多樣化答題模式**：
  - **選擇題**：自動產生 1 個正解與 3 個具迷惑性的選項。
  - **填充題**：內建「兒童專屬虛擬數字鍵盤」，阻斷平板原生鍵盤彈出干擾。
- **🏆 挑戰模式與生命值系統**：
  - 可選 10 題、20 題、30 題或無限挑戰。
  - 生命值系統（3 顆星），答錯扣星，增添挑戰刺激感。
- **🖨️ 考卷列印與自動批改**：
  - 測驗結束後自動結算分數並產生「一頁式考卷」。
  - 錯題自動以紅色標示正確解答。
  - 支援瀏覽器原生列印 (`window.print`)，自動隱藏無關 UI，匯出乾淨的 A4 PDF。
- **🥇 單機英雄榜 (Leaderboard)**：利用瀏覽器 `LocalStorage` 紀錄最高積分前 10 名玩家。

## 🛠️ 技術框架

本專案完全基於前端技術開發，以達到最輕量、最快速的載入與部署體驗：
- **HTML5**: 語意化結構。
- **CSS3 (Vanilla)**: 客製化設計系統，採用 Flexbox/Grid 佈局，並透過 `@media print` 進行列印排版優化。
- **JavaScript (ES6+)**: 原生 JS 負責 DOM 操作、隨機數學邏輯演算與 LocalStorage 資料管理。

## 🚀 如何運行與部署

### 本地端運行
由於未使用模組 (ES Modules) 或後端服務，您可以直接在本地端：
1. 將專案下載至電腦。
2. 點擊開啟 `index.html` 即可在瀏覽器遊玩。

### GitHub Pages 部署
1. 將此專案 Push 至您的 GitHub 儲存庫。
2. 進入該儲存庫的 **Settings** > **Pages**。
3. 在 **Source** 選擇 `main` (或 `master`) 分支，然後點擊 **Save**。
4. 等待幾分鐘後，即可透過 GitHub 提供之公開網址訪問。
